## Deploy Locally

First, install dependecies

```
npm i
```

Create .env file
```
NEXT_PUBLIC_SUPABASE_URL=YOUR_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_KEY

NEXTAUTH_URL="http://localhost:3000/"
NEXTAUTH_SECRET="YOUR_SECRET"

AUTH_GITHUB_ID="YOUR_ID"
AUTH_GITHUB_SECRET="YOUR_SECRET"

NEXT_PUBLIC_GOOGLE_MAPS=YOUR_KEY
```
## Database 
```
create table public.rides (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  "startingPoint" text null,
  departure timestamp without time zone null,
  description text null,
  "ishaYogaCenter" text null,
  luggage text null,
  "pricePerSeat" bigint null,
  "rideDistance" bigint null,
  seats text null,
  "user" text null,
  "startingCity" text null,
  constraint rides_pkey primary key (id)
) TABLESPACE pg_default;
```

npm run dev


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
